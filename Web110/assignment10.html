Lesson 10 taught me how to create a cascading style sheet, also known as a “CSS”. A CSS controls how text is displayed in an HTML document. A CSS controls font/background colors, fonts, sizes, and other simple visual characteristics. A CSS can be internal, external, or inline. Inline defines the style of a single HTML element. Internal defines the style of a single HTML page (Our assignments are single page, for example). External is its own separate file and is linked in each individual page. Since external CSS is its own file, you can change the entire look and feel of a website just by changing that one file.

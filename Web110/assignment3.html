Web search engines are systems that are designed to search for information on the world wide web. Search engines are able to operate by using running algorithms that help keep up with real time information. Aside from algorithms, web search engines also use web crawlers to find information. A search engine is different from a web browser. A search engine crawls, indexes, and ranks web pages across the internet to match your keywords, while web browsers fetch and display web pages, images, and videos. Search engines use a GUI and search parameters to refine the results of your search. The most popular search engines include: Google, Bing, and Yahoo. Search engines are relevant in my life and education as I use them frequently every day. Search engines collect information about every page on the web, so they can help people find exactly what they are looking for. Algorithms are used by search engines to find relevant search results from all the information they have collected. SEO (Search Engine Optimization) is what website owners use to make sure that their website is shown first after a search is made. Since there are billions of websites all fighting for the top spot, it is important that website owners optimize the contents of their websites so that interested parties can find their website. Some of the most important information that algorithms look for in websites are: words, titles, links, words in links, and reputation. It is important for website owners to host clear and relevant information on their website so when the algorithm sees it, the website can be a top result. Websites with a consistent record of engaging content, growing numbers of quality links, and relevant information are favored by the algorithms used by search engines.

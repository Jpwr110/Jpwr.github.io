I learned that a GIT is a version control system that does not store data in a file based system. GIT stores information in the form of snapshots instead. This is used to keep multiple copies of your code so you can always have access to a previous version, this especially comes in handy if/ when there are issues with the newest iteration. GIT uses two data structures: mutable and immutable. Mutable data structures can be edited and modified after creation while immutable data structures cannot change their state or content once they are initialized. GIT hub is a GIT storage website that allows you to store and share your GIT files. We will use GIT hub for submitting assignments. You can save a document/file on your computer by selecting “save as” from the drop down file menu in the top left corner of your screen. Next select the location where you want to save your file (Ex: downloads folder, documents folder, etc). Then name your file (preferably something relevant to the file) so it can be easily found later. Finally you can save your document. To go on from there you can now save that file to a USB drive. Insert the USB drive into the USB port of your computer.You will see the USB drive labeled in your file finder as an external device/drive. Next find and copy the files you want to save onto the USB. Paste the copied files onto the usb located in your file finder. Safely eject the USB to successfully save and store a backup of your files. Saving your initial files is very important as to not lose them. Saving a backup of your files to a USB drive ensures that if something bad happens to your original file storage device that you can easily recover all missing files. Traceroute shows the path your internet traffic takes to reach a website, highlighting delays at each stop. On mac (what I use) use "traceroute howtogeek.com”. When you connect to a website, traffic has to go through several stops before reaching the desired website. The traffic goes through your local router, your Internet service provider’s routers, onto larger networks, and so on. Traceroute shows us the path traffic takes to reach the website. This is helpful as it can assist you find slowdowns, locate failures, and verify routing on your own devices/internet.

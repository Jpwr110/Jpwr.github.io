Lesson 11 taught me how to include raster, vector, mp3, mp4, and embed youtube videos into my website. To include these elements into a site using html, you must use “src=” to find the source of said elements in your repository. For example, if you want to include a video, you must first make a folder named “videos” or something similar, and place your video into that folder. Once your video is in the folder, you would code src=”videos/file name”. The website will first look into the videos folder you created, and then pull the specific file name you coded.

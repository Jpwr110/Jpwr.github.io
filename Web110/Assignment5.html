The term “social media” refers to internet based, computer mediated tools that allow users to create, share, and exchange digital content (text, photo, video) within virtual communities. Social media are interactive Web 2.0 internet-based applications. Web 2.0 websites facilitate the ability of social media users to interact and collaborate with one another. Web 1.0 websites only had the ability for users to view content passively. Social media is a collection of user generated content and data, if a social media has zero users then the social media is effectively dead. These posts are created and uploaded by users using their service-specific profiles.These profiles, while customized by the user, are designed and maintained by the social media organization. Profiles of other individuals or groups interacting with one another is what creates online social networks. The honeycomb model is a hexagonal grid used to map out the digital user experience. The honeycomb model is built with: sharing, presence, relationships, identity, conversations, reputations, and groups.The benefits of participating on social media have evolved from simple social sharing and interactions into career opportunities and monetary income. Social media operates using a dialogic transmission system in which information is shared from many sources to many individual receivers. This is in direct contrast to the operation of traditional media as it functions with one source and is shared to many individual receivers.

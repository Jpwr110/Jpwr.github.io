I learned that the world wide web uses web browsers to retrieve information from across the internet. Web browsers use aggregators to collect information and RSS feeds to display it in an easy to read format. URIs are strings of characters used to identify a resource. URIs are the key to functioning bookmarks which are just URIs that are saved and stored for later retrieval. Browser caches are used for the temporary storage of web documents, such as HTML pages and images, to reduce bandwidth usage, server load, and perceived lag. I liked learning more about the behind the scenes work of web browsers as we use this technology everyday, and almost never give thought to how these services function. There are several different web browsers to choose from. The most popular of which being, Chrome, Firefox, Edge, and Safari. The primary functions of these browsers are near if not identical. The main differences lie in privacy features, memory usage, underlying technology, and customization. Chrome is the most popular browser but uses a large amount of your system's RAM and collects user data for advertising. Edge has many power saving features but still collects user data. Firefox is very customizable and has many strong privacy features but is much smaller than the other browsers. Safari is the default browser on Apple devices. Safari is optimized for apple devices and works well on Apple hardware but has less advanced features than other browsers. I liked learning about these browsers as I never understood their differences in features and data collecting. It’s helpful/important to learn about technology you use everyday especially when it comes to privacy and security in your day to day life. The most popular web browsers are all formatted (almost) the same way. They all feature an address bar, forward/back buttons, refresh button, and bookmark button all in the same locations. I find this incredibly convenient when using multiple browsers or switching browsers as since they all operate so similar there is little to no learning curve or difficulty between the browsers. It seems that the current format of web browsers has become the industry standard for browsing the internet.

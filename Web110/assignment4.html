Electronic mail (email) is a method of exchanging messages between people using electronics. Modern email systems are based on a store and forward model, meaning that the email servers accept, forward, deliver, and store messages for the user automatically. MIME is essential to email as it supports multimedia content attachments as well as different character sets. Transmitting an email from one person to another works like this. First, the email program sends the message to its outbound mail server using simple mail transfer protocol (SMTP). Next, the server finds the destination of the email using the email address of the recipient. The outbound mail server then sends the email to the destination mail server, using SMTP once again. From the destination mail server, the email is then delivered into the recipient’s mailbox, before finally, the recipient's mail user agent retrieves the message from the server using either post office protocol (POP), or internet message access protocol (IMAP). SMTPs work because of mail transfer agents (MTAs) and mail delivery agents (MDAs). Email users do not operate the MTAs and MDAs themselves, choosing web based email instead.
